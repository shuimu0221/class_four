# 《Hello Armor：装甲板位姿解算》逐字讲稿

视觉组第四讲 · 承接 Lecture 3《Hello Modern C++》· 90 分钟 · 配套 lecture4/yolo 工程

本讲稿对照《Lecture4_HelloArmor_装甲板位姿解算.pptx》（39 页）、《Lecture4_HelloArmor_教案.docx》与 lecture4/yolo 工程代码（Task 01~05 全在 src/main.cpp）编写，并完整覆盖《2025装甲板位姿解算》《Hello_Armor》两份原视频课的内容（含欧拉角、万向锁、四元数）。

> **本届改用 YOLO 版程序**：检测器是学生 lecture2 作业里那套（`tasks/` 与 `tools/` 逐字复制，一行没改）。
> 旧的手写传统 CV 版 `lecture4/class/` **不再讲授**，只作为代码保留——讲稿里**不得**把学生指向它。

**使用说明**

- 本讲稿中无标记的文字是教师可直接朗读的口播原文。
- `> 〔…〕` 是舞台提示（操作 / 板书 / 演示 / 停顿 / 应答），不需要念出来。
- 每页标题后的 ⏱ 是该页建议口播时长。
