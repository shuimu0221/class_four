> 〔操作〕鼠标圈住幻灯片上「1→2→3→4 顺时针」那一行。

接下来是最关键的一条，也是今天最容易翻车的一条：**点序**。

我们从头到尾只用一个顺序——**以左上角的灯条顶点为 1 号，然后顺时针走：1 是左灯条上端，2 是右灯条上端，3 是右灯条下端，4 是左灯条下端。** 就是左上、右上、右下、左下，绕一圈。

Task 01 你在三维里排的四个点，和 Task 02 你在图像里排的四个点，必须一个对一个、完全对齐：第 1 个 3D 点对第 1 个 2D 点，第 2 个对第 2 个，顺次往下。这个约定没有商量的余地。

为什么？因为 `solvePnP` 这个函数，它自己不知道哪根灯条在左、哪根在右。它只知道「你给我的第 i 个 3D 点，对应你给我的第 i 个 2D 点」。顺序错了，它照样给你一个解——但那个解是错的，而且它不报错。

### 【幻灯片 17】Task 01 · 填写 object_points　⏱ 5 分钟

> 〔操作〕翻到第 17 页，切到 IDE，打开 `class/src/main.cpp`，光标停到文件开头的 Task 01 注释处。

Task 01 在 `main.cpp` 的文件顶部，大概二十几行的位置。

先说一个**很多人会卡住的细节**：这一段模板，现在是**整段被双斜杠注释掉的**，你在编辑器里看到的是一片绿字。所以第一步不是填数字，是**先解注释**——把它前面的 `//` 去掉，让它变成真正生效的代码。这个提醒很重要，不然后面 solvePnP 会报「找不到 object_points 这个名字」，你还以为是别的地方错了。

> 〔操作〕指幻灯片上的模板代码块。

它现在在文件里是这样——整段都被双斜杠注释着：

```cpp
// static const std::vector<cv::Point3f> object_points {
//     {          ,           , 0 },  // 点 1
//     {          ,           , 0 },  // 点 2
//     {          ,           , 0 },  // 点 3
//     {          ,           , 0 }   // 点 4
// };
```

你要填的是每个点的前两个空——第一个是 x，第二个是 y。

这个坐标系叫**装甲板局部坐标系**：**原点在板的正中心，x 轴向右为正，y 轴向下为正。** 因为四个角点都躺在同一张平板面上，所以它们的 z 分量**全是 0**，这个 0 已经帮你填好了。

> 〔操作〕鼠标框住幻灯片上 `ARMOR_WIDTH / 2` 那一句。

代码注释里明确要求：**用「± ARMOR_WIDTH / 2」这样的写法来填，不要写死小数。** 为什么？因为装甲板的尺寸会改，你写成 0.0675 这种硬编码，尺寸一改你全得重来；写成表达式，尺寸改了它自动跟着变。宽度方向用 `ARMOR_WIDTH / 2`，高度方向用 `LIGHTBAR_LENGTH / 2`——一个是半宽，一个是半高。

现在我们一起推，我不给答案。

它在上方。y 轴是朝下的——越往下 y 越大——那最上面这个点，y 是正的还是负的？

> 〔应答〕

> · 冷场 → 「我给思路不给答案：先别管正负，把绝对值填进去，四个点都是半宽和半高；正负号，就看你这个点在中心的哪一侧。剩下的你们自己推。」

好，剩下的三个点，照同样的道理自己推。我不念答案。

再提几个我见过的常见错误，你们避开：

第一，**正负号搞反**——最常见。第二，**把 0.135 当成半宽**——0.135 是灯条中心间距、是两个灯条中心的距离，半宽是它的一半，别再除第二次。第三，**忘了解注释**，就是你前面遇到的那个。第四，**顺序写错**——四个点的注释都给你标了号，别填岔行。

> 〔操作〕切到 `tasks/armor.hpp`，指一下 `Armor` 结构体里的 `center`。

还有一句提前提醒：**`Armor` 结构体里那个 `center`，不是装甲板四边形的角点。** 它是两根灯条中心点的平均，是两根灯条中间的一个虚拟点，不是四个角里的任何一个。PnP 要的是能和物理 3D 点一一对应的那四个真实端点，别拿 `center` 来凑数。

### 【幻灯片 19】Task 03 · 调用 cv::solvePnP　⏱ 3 分钟

### 【集合收尾话术】

平移就是 `tvec`，三个数；旋转就是 `rvec`，也是三个数。它们现在已经在你的程序里解出来了，只是还没打到屏幕上。

但是——你有没有想过一个问题？`rvec` 这三个数，它到底在说什么？是方向？是角度？为什么偏偏是三个，不是四个、也不是九个？
