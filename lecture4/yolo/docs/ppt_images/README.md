# PPT 配图

`build_ppt.py` 里每处配图都是一个占位框。本目录下的图片会被**自动替换进去**：
占位标签里出现 `IMAGE_KEYS` 中的关键词，就换成对应的 `.png`；找不到文件则照旧画占位框。

重新生成：

```bash
# 从 assets/video.avi 抽帧 + 真实检测/解算（需要 opencv-python + openvino）
python build_ppt_images.py
# 概念示意图（需要 pillow）
python build_ppt_diagrams.py
```

两个脚本都输出到本目录，然后重跑 `python build_ppt.py` 即可。

### 补图时注意

- **第 14 页和第 16 页要一致**：都是装甲板的点序图，标注口径统一用 `0/1/2/3`（0-based），
  与代码里的 `armor.points.at(0)` 对齐。实物上如果贴了 1/2/3/4，讲的时候要说明差一位。
- **第 21 页的报错文本**：讲稿里写的是 `YAML::BadFile` / `what(): bad file: configs/yolo.yaml`，
  这是**推导出来的**，还没有在真机上验证过。截图前先在开发机上实跑一遍，以实际输出为准；
  如果实际报错不同，讲稿和 `_context.md` 里的那段要一起改。
- 占位框**不影响上课**：它就是一个灰色圆角框 + 一行斜体说明，投影出来老师能照着念
  「这里应该有一张……」。所以补图是锦上添花，不阻塞使用。
